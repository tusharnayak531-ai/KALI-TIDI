ForgeFit Support

Need help using ForgeFit for iPhone?

Common questions

Do I need an account? No. ForgeFit V1.0 stores fitness records on your device.

How do I transfer logs from the website? On the website, export JSON from Settings; in ForgeFit iOS go to Settings → Import web or iOS backup.

How do I back up or delete records? Use the Export JSON backup and Delete all local data options under Settings.

Contact and bugs

To request help or report a problem, open a GitHub support issue. Do not include sensitive fitness information in a public issue.
